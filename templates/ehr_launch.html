EHR Launch · SMART on FHIR

Open this workbench from inside an EHR on the patient in context, the way Bill Chen's Medplum demo does. The EHR provides the patient's MRN, and we match it to a workbench patient. Wearable data stays outside the EHR (JP, Sep 29). Medplum is the sandbox; Epic uses the same flow later. All patients here are synthetic.

How a launch works

Clinician opens patient in EHR→Apps → this workbench→ /ehr/launch (iss, launch)→EHR login + scope consent→ /ehr/callback → token + Patient→MRN → /patient/<id>

Connect Medplum

  1. Download synthetic patients (FHIR Bundle), then upload it in Medplum → Batch.
  2. Medplum → Admin → Project → Clients → New: Launch URI {{ launch_url }}, Redirect URI {{ redirect_uri }}.
  3. Restart the workbench with SMART_CLIENT_ID=… (and SMART_CLIENT_SECRET if given).
  4. Open a patient in Medplum → Apps → this client → Choose scope → Set Scope.
